# Security Guidelines

Incident reports for Tenant A must be filed within one hour of detecting a security event and escalated to the security lead on call.

Employees should never send API keys over chat. Secrets must be stored in the company vault and rotated immediately if accidental exposure is suspected.

Quarterly phishing drills are mandatory for all contractors and full-time staff, and completion is tracked by the compliance team.

Approved production access requires MFA, a managed device, and an active ticket referencing the change window.
